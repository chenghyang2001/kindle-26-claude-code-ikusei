# PRD：簡易待辦事項（Todo）網頁應用

## 1. 背景與目標
提供零安裝、零註冊、離線可用的個人待辦清單。成功標準：使用者 10 秒內完成第一筆待辦，重新整理後資料不遺失。

## 2. 範圍
### 包含（MVP）
- F1 新增待辦（Enter 或按鈕；空白字串不接受；前後空白去除；上限 200 字）
- F2 切換完成狀態（勾選框）
- F3 刪除單筆待辦
- F4 資料持久化於 localStorage（key：`k26-todos`）
- F5 篩選：全部 / 未完成 / 已完成
- F6 顯示未完成數量；「清除已完成」按鈕

### 不包含
編輯、排序、到期日、雲端同步、帳號。

## 3. 使用者故事
- 身為使用者，我想輸入一件事並按 Enter，它就出現在清單中。
- 身為使用者，我想勾選完成，讓我知道哪些做完了。
- 身為使用者，我想關掉分頁再打開，清單還在。
- 身為使用者，我想只看未完成的項目，專注在剩下的事。

## 4. 資料模型
```json
{ "id": "字串（時間戳+亂數）", "title": "字串", "done": false, "createdAt": 1700000000000 }
```

## 5. 非功能需求
- 零外部依賴，單一 `index.html` + `app.js` + `style.css`
- 安全：使用者文字只用 `textContent` 呈現
- 容錯：localStorage 不可用或資料損毀時，不讓頁面崩潰，並顯示提示
- 手機寬度可用（RWD）

## 6. 邊界案例
| 情境 | 預期 |
| --- | --- |
| 輸入全空白 | 不新增，顯示提示 |
| 輸入 `<script>` | 以純文字顯示 |
| localStorage 內容不是合法 JSON | 重設為空清單並提示 |
| localStorage 被停用（隱私模式） | 仍可在記憶體中操作，顯示「無法儲存」提示 |
| 超過 200 字 | 截斷為 200 字 |
