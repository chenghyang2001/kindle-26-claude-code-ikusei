# 腦力激盪：待辦事項網頁應用

## 問題
想要一個打開就能用、不必註冊、不需伺服器的個人待辦清單。

## 目標使用者
- 個人使用者，在單一瀏覽器記錄當天要做的事

## 點子清單（發散）
| # | 點子 | 價值 | 成本 | 決定 |
| --- | --- | --- | --- | --- |
| 1 | 新增待辦 | 高 | 低 | ✅ MVP |
| 2 | 標記完成 / 取消完成 | 高 | 低 | ✅ MVP |
| 3 | 刪除待辦 | 高 | 低 | ✅ MVP |
| 4 | 重新整理後資料還在（localStorage） | 高 | 低 | ✅ MVP |
| 5 | 篩選：全部 / 未完成 / 已完成 | 中 | 低 | ✅ MVP |
| 6 | 剩餘數量計數、清除已完成 | 中 | 低 | ✅ MVP |
| 7 | 編輯文字（雙擊） | 中 | 中 | ⏸ 下一版 |
| 8 | 拖曳排序 | 低 | 高 | ❌ |
| 9 | 雲端同步 / 多裝置 | 中 | 高 | ❌（違反「不需伺服器」） |
| 10 | 到期日與提醒 | 中 | 中 | ⏸ 下一版 |

## 收斂
MVP = 點子 1～6。技術限制：純 HTML + JS、localStorage、零依賴。

## 風險
- localStorage 被清除 → 資料遺失（接受，於 PRD 註明）
- localStorage 內容損毀 → JSON.parse 失敗，需容錯
- 使用者輸入含 HTML → XSS，需用 textContent
