# 番茄鐘小工具（FocusTomato）PRD

## 1. 背景

- 知識工作者和學生常被通知、訊息打斷，一次能專注的時間平均不到 15 分鐘，很難完成需要深入思考的任務。
- 市面上的番茄鐘 App 大多要先註冊、廣告多、功能雜；使用者其實只想「按一下就開始計時」。
- 目標族群：18～40 歲的學生、軟體工程師、自由工作者。主要在電腦瀏覽器上工作，其次用手機。
- 為什麼現在做：遠距和混合辦公已經很普遍，自己管理時間的需求變高。純前端工具開發成本低，可以很快驗證需求。

### 假設

- 第一版是單頁網頁應用（PWA），沒有後端，資料只存在使用者瀏覽器的本機。
- 採用經典番茄工作法：專注 25 分鐘、短休息 5 分鐘，每 4 個番茄後長休息 15 分鐘。
- 介面只有繁體中文，不做多語系。
- 免費，沒有廣告。

## 2. 目標

### 產品目標

- 第一次開啟到開始第一個番茄 ≤ 5 秒（不用註冊、不用設定）。
- 上線 30 天內，7 日留存率 ≥ 40%。
- 活躍使用者平均每天完成 ≥ 4 個番茄。
- 計時誤差：每 25 分鐘 ≤ 1 秒，切換分頁或鎖定螢幕後回來也要達到。
- 上線第一個月，使用者回報的計時 bug ≤ 3 件。

### 非目標（本版不做）

- 帳號註冊、登入、跨裝置雲端同步。
- 團隊協作、多人一起專注、排行榜等社交功能。
- 待辦清單管理（每個番茄只能填一個簡短的任務名稱）。
- 原生 iOS／Android App、桌面應用程式。
- 封鎖網站或 App 這類強制專注功能。
- 付費方案、廣告。

## 4. 功能需求

| 編號 | 功能 | 說明 | 優先序 |
| --- | --- | --- | --- |
| FR-01 | 一鍵開始計時 | 首頁中央顯示大型倒數（MM:SS）和「開始」按鈕。預設專注 25:00，按下就立刻開始倒數。 | P0 |
| FR-02 | 暫停／繼續／重設 | 計時中顯示「暫停」，暫停後顯示「繼續」。「重設」讓目前階段回到完整時長，而且不算進完成數。 | P0 |
| FR-03 | 階段自動循環 | 專注結束 → 短休息；每完成第 4 個專注 → 長休息；休息結束 → 回到專注，但停在「待開始」，等使用者按開始。 | P0 |
| FR-04 | 結束提醒 | 階段結束時播放提示音（可在設定裡關掉）。使用者授權後也會跳出桌面通知，寫明下一個階段的名稱和時長。 | P0 |
| FR-05 | 分頁標題倒數 | 瀏覽器分頁標題即時顯示剩餘時間和階段，例如「12:34 專注中」。 | P0 |
| FR-06 | 跳過階段 | 提供「跳過」按鈕，直接進入下一個階段。被跳過的專注不算進完成數。 | P1 |
| FR-07 | 自訂時長 | 設定頁可調整專注（1～90 分鐘）、短休息（1～30）、長休息（1～60）、長休息間隔（2～8 個番茄），只接受整數。 | P1 |
| FR-08 | 任務名稱 | 專注開始前可以填任務名稱（最多 50 字，可留空），跟這個番茄的紀錄一起存起來。 | P1 |
| FR-09 | 統計 | 顯示今天完成的番茄數、今天專注的總分鐘數，以及最近 7 天每天完成數的長條圖。 | P1 |
| FR-10 | 本機儲存 | 設定和番茄紀錄存在瀏覽器本機，重新整理或關掉再開都不會不見。紀錄保留 90 天。 | P1 |
| FR-11 | 清除資料 | 設定頁有「清除所有紀錄」，要再確認一次才會執行。 | P1 |
| FR-12 | 鍵盤快捷鍵 | 空白鍵：開始／暫停；R：重設；S：跳過。游標在文字輸入框裡時，快捷鍵不作用。 | P2 |
| FR-13 | 深色模式 | 預設跟著系統主題，也可以手動切換淺色或深色，選擇會被記住。 | P2 |
| FR-14 | 可安裝 | 支援 PWA，可安裝到電腦桌面或手機主畫面，離線時仍然可以正常計時。 | P2 |

## 5. 非功能需求

| 編號 | 類別 | 需求 | 驗證方式 |
| --- | --- | --- | --- |
| NFR-01 | 效能 | 在 4G 網路和中階手機上，第一次載入到可以操作（TTI）≤ 2 秒，之後再載入 ≤ 1 秒。 | Lighthouse 行動版測試 |
| NFR-02 | 效能 | 剩餘時間用系統時間戳計算，不靠計時器一秒一秒累加。連續計時 25 分鐘（包含切換分頁、鎖定螢幕）誤差 ≤ 1 秒。 | 自動化測試，和系統時鐘對比 |
| NFR-03 | 效能 | 第一次載入的程式和資源，gzip 後總大小 ≤ 200 KB。 | 檢查建置產物大小 |
| NFR-04 | 可用性／無障礙 | 符合 WCAG 2.1 AA：文字對比 ≥ 4.5:1，所有操作都能只用鍵盤完成，每個按鈕都有可讀的無障礙名稱。 | axe 掃描沒有嚴重問題，再加人工用鍵盤走一遍 |
| NFR-05 | 可用性／無障礙 | 階段切換時，螢幕閱讀器會念出狀態（例如「專注結束，開始短休息 5 分鐘」），但不會每秒念倒數。 | 用 NVDA／VoiceOver 手動測試 |
| NFR-06 | 可用性 | 新使用者不看說明，5 秒內就能開始第一個番茄；5 位測試者至少 4 位做到。 | 可用性測試 |
| NFR-07 | 相容性 | 支援 Chrome、Edge、Firefox、Safari 最新兩個主要版本；畫面寬度 320px～2560px 版面都不會跑掉。 | 跨瀏覽器測試矩陣 |
| NFR-08 | 隱私與安全 | 不收集個人資料，不用第三方追蹤或分析服務。所有資料只存在本機，不傳到任何伺服器。 | 檢查網路請求：第一次載入後沒有任何對外請求 |
| NFR-09 | 隱私與安全 | 任務名稱一律當成純文字顯示，輸入 HTML 或程式碼也不會被執行。 | 輸入 `<script>alert(1)</script>`，確認只顯示成文字 |
| NFR-10 | 可維護性 | 計時和階段切換邏輯的單元測試覆蓋率 ≥ 90%，所有測試在 CI 自動執行。 | CI 覆蓋率報告 |
| NFR-11 | 可維護性 | 本機資料格式帶版本號。格式升級時自動轉換舊資料，紀錄不會不見。 | 遷移測試：用舊版資料載入新版 |
